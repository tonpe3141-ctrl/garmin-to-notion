## ワークフロー

### STEP 1: Google ドライブからログ取得

リクエストに応じた対象を抽出する：

- 「今日」→ セクション③の最新1件
- 「直近」「最近」→ セクション③の直近3〜5件
- 「今週」→ セクション③の今週分（月〜日）
- 「今月」→ セクション③の当月全件 ＋ セクション④の週次サマリーで補完
- 「コンディション確認」→ セクション①の健康データ概要を参照

### STEP 2: 重複チェック（Notion登録前に必須）

Notion:notion-search で「[練習種別] [YYYY-MM-DD]」を検索  
→ 既存ページが見つかれば登録スキップ  
→ なければ STEP 3 へ進む

### STEP 3: コーチ分析

#### 練習種別の判定

| 条件 | 判定 |
|------|------|
| 平均心拍 < 140bpm ＋ 距離 ≥ 8km | Eペース走 or Mペースロング |
| 平均心拍 150〜167bpm ＋ 均等ペース | Mペース走 |
| 平均心拍 167〜175bpm ＋ 均等ペース | Tペース走 |
| ラップ間心拍が激しく変動 or 短インターバルラップ | インターバル |
| 平均心拍 < 130bpm ＋ 距離 < 6km | リカバリー |
| 200〜400m高速ラップ ＋ 本間に完全回復を繰り返す | レペティション |

トレーニング効果欄（Vo2Max / 乳酸閾値 / ベース等）も参考に総合判定する。

#### 評価軸（5軸）

**① ペース管理**

- 目標ペース対比の達成度
- ラップのばらつき（後半失速 vs. ネガティブスプリット）
- レペティションは各本のペース精度とフォーム再現性を重点評価

**② 心拍コントロール**

- LT値（172bpm）との関係
- HR上限の遵守（E: ≤140 / M: ≤167 / T: ≤176）
- 心拍ドリフト傾向（同ペースでHRが上昇していないか）
- ※レペティションは心拍管理不要。ペースとフォームで評価する

**③ フォーム指標（ランニングダイナミクス）**

| 指標 | 良好 | 標準 |
|------|------|------|
| ピッチ | 180〜190spm | 170〜180spm |
| 接地時間 | < 250ms | 250〜270ms |
| 上下動 | < 8cm | 8〜10cm |

※上下動はドライブの値を×10して評価（例: 0.8 → 実際8cm）

**④ 疲労・コンディション評価（直近3〜5件横断）**

- 連続強度トレーニングによる蓄積疲労
- 同ペースで心拍が上昇している場合は疲労蓄積サイン
- 週間走行距離の前週比 +10% 超 → 過負荷リスク
- セクション①の健康データも参照し、以下を警戒サインとして扱う：
  - HRV が前週比 -10% 以上 → 強度を落とすか休養を推奨
  - ボディバッテリーの最低値 < 25 が連日 → オーバートレーニングの疑い
  - トレーニング準備度 < 50 → 高強度練習を回避
  - 安静時心拍が平常比 +5 以上 → 疲労蓄積の警戒

**⑤ 総合評価**

| 評価 | 基準 |
|------|------|
| ◎ 完璧 | 全指標が計画通り |
| ○ 合格 | 概ね計画通り、軽微な逸脱あり |
| △ 要調整 | HR上限超え or ペース未達 or 課題あり |
| ✕ 中止 | 途中終了・体調不良 |
