# iPhone ウィジェット（サブ3コーチ）

直近のランと次のランを、ダッシュボードを開かずにホーム画面・ロック画面で見るためのウィジェット。

```
Claude Routine（毎日12:00）──書く──▶ Notion「📱 ウィジェット用データ」の JSON
                                              │
iPhone の Scriptable ウィジェット ◀──読む──────┘（Notion API）
```

ダッシュボード（claude.ai の Artifact）は claude.ai にログインしないと読めないため、ウィジェットからは直接取得できない。
そこで Routine が要点だけを Notion のページに書き、ウィジェットがそれを読む構成にしている。
JSON は `scripts/export_widget_data.js` がダッシュボードの DATA から機械的に作る（`docs/daily_coach_routine.md` の STEP 6.8）。

## 表示内容

| サイズ | 内容 |
|--------|------|
| 小 | 次のラン（メニュー・ペース・心拍）、レースまでの日数 |
| 中 | 左: 直近のラン（総合評価・距離・ペース・心拍）／右: 次のラン（要点の一文つき） |
| 大 | 中の内容 ＋ その先5日の予定、今週の距離 |
| ロック画面（長方形） | 次のラン、ペースと心拍、前回の評価 |
| ロック画面（円形） | レースまでの日数 |
| ロック画面（インライン） | 次のラン |

- 次のランは「今日以降で最初の予定」。12:00 の更新前は、その日のメニューが「今日」として出る。
- Routine が止まっても、受け取り済みの1週間の予定から今日のメニューを出し続ける。更新が遅れていると右下に ⚠ が出る。
- タップするとダッシュボードが開く。

## セットアップ（初回のみ・約5分）

### 1. Notion のインテグレーションを作る

1. https://www.notion.so/profile/integrations を開き、「新しいインテグレーション」を作る
   - 名前: `サブ3ウィジェット`（任意）
   - 種類: 内部
   - 機能: 「コンテンツを読み取る」だけにチェック（書き込みは不要）
2. 作成後に表示される「内部インテグレーションシークレット」（`ntn_` で始まる）をコピーしておく

### 2. ページにインテグレーションを接続する

Notion で「各種連携」→「📱 ウィジェット用データ」を開き、右上の `…` → 「接続」→ 上で作ったインテグレーションを選ぶ。

これを忘れると、ウィジェットに「ページにインテグレーションが接続されていません」と出る。

### 3. Scriptable にスクリプトを入れる

1. App Store から **Scriptable**（無料）を入れる
2. Scriptable で右上の `＋` → 新規スクリプトに `running_widget.js` の中身を全部貼り付け、名前を `サブ3コーチ` にする
   （Mac から iCloud Drive の `Scriptable` フォルダにファイルを置いても同じ）
3. スクリプトを一度タップして実行 → トークン入力欄に手順1のシークレットを貼り付けて保存
   - トークンは iPhone のキーチェーンにだけ保存される
   - 続けて「プレビュー（中）」を選ぶと表示を確認できる

### 4. ホーム画面・ロック画面に置く

- **ホーム画面**: 長押し → 左上の `＋` → Scriptable → サイズを選んで追加 →
  追加したウィジェットを長押し →「ウィジェットを編集」→ Script に `サブ3コーチ` を選ぶ
- **ロック画面**: ロック画面を長押し →「カスタマイズ」→ ロック画面 → ウィジェット欄に Scriptable を追加 →
  タップして Script に `サブ3コーチ` を選ぶ

## 困ったとき

| 表示 | 原因と対処 |
|------|------------|
| トークンが無効です | シークレットが違う。Scriptable でスクリプトを実行 →「トークンを設定し直す」 |
| ページにインテグレーションが接続されていません | 手順2をやる |
| JSON ブロックが見つかりません | Notion のページが手で編集された。Routine の次回実行で戻る |
| ⚠ 9/24 12:00 更新 | Routine が当日分を書いていない。https://claude.ai/code/routines で実行履歴を確認する |

更新の頻度は iOS が決める（おおむね15分〜1時間おき）。スクリプトは 12:15 と 0:05 に再描画を依頼している。
